# GEA 项目面试资料包

这套资料基于当前仓库的实际代码和已有架构文档整理，目标是让你能够用口语把项目讲完整。项目在仓库中使用的名称是 `Cognara AI recovery rebuild`，面试时可以统一称为“GEA：AI 用户研究与通用智能体平台”。

## 建议阅读顺序

1. `01-简历包装.md`：挑选简历上的项目描述和技术栈。
2. `04-项目讲解稿.md`：背 30 秒、1 分钟和 3 分钟版本。
3. `02-面试问题与回答.md`：按问题练习，回答都写成了口语风格。
4. `03-技术要点速查.md`：面试前快速复习架构、数据、可靠性和安全。

## 口径边界

- 项目已经实现了本地账户、研究创建、计划确认、任务队列、研究 Harness、报告证据链、Universal Agent、SSE、技能治理和独立 Sandbox Runner。
- 生产环境仍需要配置 AI Provider、Supabase/PostgreSQL、对象存储、邮件、支付和独立 Runner 等外部服务。面试中不要把“代码已具备接口”说成“已经大规模线上运行”。
- 合成 Persona 和合成访谈用于方向性探索，不能表述为真实用户访谈或统计学验证。报告会区分网页事实、平台观察、AI 合成推演和模型建议。
- 如果你不是每个模块的主要作者，使用“我负责/我设计”前，把范围替换成你实际承担的模块；技术原理和追问准备可以直接复用。

## 一句话定位

这是一个把“研究问题 -> 证据采集 -> Persona/访谈 -> 报告 -> 可追溯审计”串成闭环的 AI 用户研究平台，同时提供一个受权限、预算、版本和沙箱约束的通用 Agent 执行层。
