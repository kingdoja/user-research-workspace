# 简历包装

## 项目名称

GEA（Cognara AI）——AI 用户研究与通用智能体平台

## 简历一行版

基于 Next.js、TypeScript、PostgreSQL/Supabase 和大模型 Provider 构建 AI 用户研究平台，覆盖研究计划、联网检索、合成 Persona/访谈、证据图谱、报告质量评审、Universal Agent、SSE 实时进度和受限代码沙箱执行。

## 推荐项目描述（中高级岗位）

负责设计并实现一套 AI 用户研究与通用智能体平台，将用户 Brief 转换为可确认、可恢复、可审计的研究运行。采用 Next.js App Router + TypeScript 构建产品和 API，使用 PostgreSQL 持久化工作区、研究计划、任务 DAG、运行状态、证据和事件；通过独立 worker、租约队列、幂等键、checkpoint、重试和取消机制支撑长时任务。研究侧实现公开网页/可选官方连接器、Persona 复用与生成、合成访谈、证据图谱和“生成-评审-定向修订-定稿”的报告 DAG；Agent 侧通过结构化动作协议调用内置产品工具和版本化 Skill，并用 SSE 输出可审计事件。另以独立 Sandbox Runner 在 Docker/Rootless Podman 中执行 JavaScript/Python Skill，启用非 root、只读文件系统、无网络、资源限制和优雅退出。

## 推荐项目描述（偏后端/基础设施岗位）

设计 PostgreSQL-backed AI execution runtime：将研究运行拆成带依赖的 `study_tasks` ledger，由 worker 领取带 lease 的 job，按任务状态、幂等键和 checkpoint 恢复；所有工具调用绑定 Skill 版本、Context retrieval snapshot、预算和 policy。实现 SSE 事件流、Last-Event-ID 断线续传、失败分类与重试、waiting-input 恢复、动态任务 mutation 和 trajectory evaluation。通过独立 Sandbox Runner 隔离不可信 Skill，HTTP Runner 只接受受 schema 校验的请求并返回 JSON 结果。

## 推荐项目描述（偏全栈/产品工程岗位）

从公开产品重建并扩展 GEA AI 研究平台：完成账户与工作区、研究向导、研究进度时间线、报告查看、Persona 库、访谈项目、Universal Agent、技能管理和平台协作页面。前端使用 React Server/Client Components 和 App Router，后端用 Route Handler 调用领域服务，长任务通过数据库队列和 SSE 驱动 UI，保证刷新、断线和重新进入页面后仍能从权威状态恢复。

## 技术栈写法

`TypeScript`、`Next.js 16 App Router`、`React 19`、`PostgreSQL/Supabase`、`PGlite（本地恢复）`、`Zod`、`OpenAI-compatible Provider / Responses API`、`SSE`、`Docker/Rootless Podman`、`Prometheus metrics`、`pnpm`、`ESLint`。

## 技术亮点关键词

- Plan-and-Execute research harness
- PostgreSQL task ledger / DAG
- Worker lease、幂等、checkpoint、重试和取消
- Evidence-grounded report / evidence graph
- Structured Agent action protocol
- Skill version pinning / capability grants
- Context snapshot、混合检索和来源审计
- SSE progress events / Last-Event-ID replay
- Sandboxed code execution
- Policy-driven rollout / trajectory evaluation

## 面试官追问“你的贡献是什么”时的模板

“我主要把 AI 调用从一次性接口，做成了可治理的执行系统。核心工作有三块：第一，把研究拆成数据库里的任务 ledger，解决长任务的排队、依赖、重试和恢复；第二，把模型输出限制成 Zod 校验过的结构化动作，再由 Harness 做权限、预算、Skill 版本和报告门槛的二次校验；第三，把来源、证据、工具事件和最终报告串起来，用户可以看到进度，工程侧也能回放一次运行为什么这么做。对于不可信代码，我把执行放到独立 Runner 的临时容器里，Next.js 进程本身不执行上传代码。”

## 不建议写进简历的表述

- “完全自主、完全准确的 AI Agent”。当前研究执行仍有确定性 Harness 和 rollout gate。
- “真实用户访谈/真实行为数据”。默认能力包含合成 Persona、合成访谈和公开网页方向性证据。
- “生产已支持任意联网代码执行”。Sandbox 默认无网络，网络 grant 会在平台侧被拒绝。
- “使用 LangGraph 管理生产工作流”。当前决策是保留自研 Postgres Harness，没有把 LangGraph 作为生产 source of truth。
- 没有代码或监控证据支撑的 QPS、节省成本、准确率和用户数。
