## 可以直接复述的技术定义

**任务 ledger**： “把一次运行拆成数据库中有状态的任务记录，记录依赖、输入、输出、错误和重试，而不是把流程只存在内存里。”

**幂等**： “同一业务请求重复到达，系统最多产生一次业务效果；实现上用稳定 key、请求 hash 和唯一约束兜底。”

**Lease**： “任务暂时归某个 worker 执行，带过期时间并可续租；worker 消失后，过期任务才能被别的 worker 接管。”

**Checkpoint**： “在可恢复边界保存状态，恢复时从最后一个已确认状态继续，不重新执行已经完成的副作用。”

**Evidence grounding**： “每个结论关联来源和证据项，并记录支持关系、置信度和局限；没有证据时降低结论等级。”

**Capability grant**： “Skill 可以做什么以及作用范围的明确授权，执行前和运行绑定时都要检查。”

**SSE**： “浏览器与服务器保持一条单向 HTTP 连接，服务器持续发送文本事件；它适合进度通知，不替代数据库事务。”
